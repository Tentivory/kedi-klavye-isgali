# Kedi Klavye İşgali

## Kediler Neden Kazanır?

Bu simülatör, kedilerin klavyeleri nasıl stratejik olarak ele geçirdiğini gösterir. Bilimsel araştırmalar (yani benim gözlemlerim) gösteriyor ki kediler iş yapmanızı engellemek için evrimleşmiştir.

### Özellikler
- Gerçek kedi emojileri
- Anında iş durdurma
- Yenilmez kedi stratejisi

### Çalıştırma
```bash
python kedi_isgali.py
```

Kedi yatar, siz durursunuz.
